# Privacidad

La aplicación Recorta no recopila, almacena ni transmite información personal. No utiliza cuentas, analítica, publicidad ni servidores externos.

Las fotografías se leen, procesan y guardan localmente en el Mac. Antes de reemplazar una fotografía, Recorta guarda una copia exacta del archivo anterior dentro de la carpeta oculta `.recorta-backups`, ubicada en la carpeta de fotografías elegida por la persona usuaria.

El sitio web utiliza Vercel Web Analytics para registrar estadísticas agregadas y anónimas, como visitas, páginas consultadas, país aproximado, dispositivo y sitio de procedencia. Vercel Web Analytics no utiliza cookies. El sitio no contiene cuentas, publicidad ni formularios de seguimiento.
