# Contribuir a Recorta

Gracias por ayudar a mejorar Recorta. Antes de proponer un cambio, abre un issue que describa el problema, la versión de macOS y el modelo de Mac. No adjuntes fotografías privadas.

Para desarrollar necesitas macOS 14 o posterior y las herramientas de desarrollo de Apple.

```bash
swift build
./check.sh
./build-app.sh
```

Mantén cada cambio enfocado, explica cómo lo verificaste y conserva el flujo principal de Recorta: encuadrar, Enter y continuar.
