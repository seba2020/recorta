Privacidad

Tus fotos no salen de tu Mac.

Recorta no tiene cuentas, anuncios, seguimiento ni servidores. Todo el procesamiento ocurre localmente.

Tus originales

Un respaldo antes de cada cambio.

La fotografía se reemplaza para mantener el flujo rápido. Antes, Recorta guarda una copia exacta dentro de .recorta-backups en la carpeta seleccionada.

Conserva los respaldos hasta revisar tus resultados. Si recortas la misma foto varias veces, se crea una copia nueva en cada ocasión.

Primera apertura

Cómo abrir esta beta.

Recorta todavía no está notarizada por Apple. macOS pedirá una autorización manual solamente la primera vez.

Descarga el ZIP, descomprímelo y arrastra Recorta.app a Aplicaciones.

Intenta abrir Recorta. macOS mostrará una advertencia; ciérrala.

Abre Ajustes del Sistema → Privacidad y seguridad.

Presiona Abrir igualmente y confirma. A partir de entonces se abrirá normalmente.
